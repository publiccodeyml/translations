# publiccode.yml translations

Translations of the documentation of the
[publiccode.yml Spec](https://github.com/publiccodeyml/publiccode.yml).

Each version of the Spec has its own directory, with one
subdirectory per language:

| Directory | Spec                  | publiccode.yml branch |
|-----------|-----------------------|-----------------------|
| `v0/`     | 0.x                   | `main`                |
| `v1/`     | 1.0 release candidate | `1.0-rc`              |

| Subdirectory | Language |
|--------------|----------|
| `it/`        | Italian  |
| `de/`        | German   |
| `fr/`        | French   |

To change a translation, edit the files under the directory of the
version you are translating.

## History

These files were moved out of publiccode.yml with their history. In
the commits made before the move, `#N` references were rewritten to
`publiccodeyml/publiccode.yml#N`.
